# M0VE interface system

The existing property illustrations, datasets, page structures and interactions are retained. This pass aligns the family and improves readability.

- Display: Georgia serif, regular, tracking no tighter than -0.035em.
- Body and controls: M0VE Sans (Manrope, existing licensed font served by the homes-for-sale project), Arial fallback.
- Ink #153345, warm paper #FAF8F3, secondary text #536570, action purple #6945C5.
- Main reading copy 15–17px; controls 13–16px; supporting evidence at least 12px where practical.
- Header: actual M0VE logo, contextual primary links, visible mobile menu, 44px controls.
- Shapes: 10px buttons, 12–16px panels; illustrations and atlas compositions retain their own forms.
- Reduced motion, visible focus, semantic labels and existing factual/data caveats are preserved.
- Homepage: active hero message holds one position; no incremental downward displacement.
- Valuation: exact SVG plan geometry with space, energy and condition explanation controls.

Assets: the shared logo is served from m0ve-home-page; the shared font is served from m0ve-homes-for-sale. These URLs are first-party project dependencies.
